# 播浪

中文名：**播浪** · 前缀 `livewave` · 端口 **6400 / 11400**

## 骨架

**互动事件入流 → 事件时间水位线推进 → 热度窗关闭发射 → 迟到修正/撤回 → 窗输出与撤回互证**

皮：直播间点赞/送礼互动。去皮是事件时间窗计算 + 允许迟到与撤回，不是直播运营后台 CRUD，不是点击会话空闲切开。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6400
# 入流 → 灌「准时热度样例」→ 水位线/热度窗/关窗发射 → 灌「关窗准时拒收样例」看拒收 →
# 再灌「迟到修正样例」看撤回 → 超迟到旁路 → 贯验
```

## 关窗发射口径（全局唯一：关闭即冻结）

水位 ≥ 窗止 时，关窗事务（条件写闸、单提交）把窗 开启→已关闭，并在**同一事务内物化发射快照**
（表 `关窗发射`：发射号/关闭处理时/关闭时水位/快照赞送礼笔数版本/口径），发射结果可核对。

关窗后同窗事件按**处理时**分流：

| 情形 | 判据 | 处置 |
| --- | --- | --- |
| 关窗后准时 | 处理时 ≤ 关闭处理时 | **拒收**：命运=关闭拒收、不挂窗键，写 `关窗拒收` 证据；合计与快照不变 |
| 显式迟到修正 | 处理时 > 关闭处理时 且 水位 < 窗止+允许迟到 | 走撤回单改现行合计；发射快照冻结不动 |
| 超允许迟到 | 水位 ≥ 窗止+允许迟到 | 旁路匣 |

只读接口 `GET /api/关窗发射`（可带 `状态=` 或 `窗键=`）返回：窗键、关闭态、发射快照、现行合计、
拒收/续写/迟到修正证据、`valid`（交叉核对关闭态↔发射记录↔事件合计↔快照+修正净增量）。

并发：SQLite WAL + `状态='开启'` 条件写闸 + busy_timeout，关窗与入流被线性化，写锁冲突整单回滚，
绝不留「状态已关闭、合计继续被准时路径累加」的半截分叉。

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 互动事件 | 带事件时/处理时的点赞送礼 |
| 水位线 | 每房事件时水位 + 允许迟到秒 |
| 热度窗 | 翻滚窗；开启累计，关闭发射 |
| 关窗发射 | 关窗事务物化的发射快照（只读核对） |
| 关窗拒收 | 关闭即冻结口径下被拒收的同窗准时事件证据 |
| 撤回单 | 已关闭窗被允许迟到事件修正 |
| 旁路匣 | 超允许迟到 |
| 窗贯验 | 窗合计 ↔ 事件合计 ↔ 发射快照 ↔ 末次撤回 |
